# Customer Response Rate Prediction 

Customer Response Rate Prediction and the Main Causes Using Machine Learning

## Project Overview
Knowing the customer response rate to renewal and the main causes leading to it is important, as it can be used to measure overall customer satisfaction and help predict future revenue
## Tech Stack
| Component   | Technology                          |
|-------------|-------------------------------------|
| Programming | Python                              |
| Libraries   | Pandas, Numpy, Matplotlib, Seaborn  |
| Model Type  | Classification                      |

## Key Features
* Performed EDA, preprocessing, encoding, and feature selection
* Created a stratified model to predict customer response
* Identified top drivers of Non-Response rate
* Visualised feature importance

##  Visualisations

| Visualisation | Purpose |
|---------------|---------|
| CLV Distribution (Log Scale) | Understand customer value distribution |
| Non-Response Rate by Month | Identify monthly patterns |
| Feature Importance Bar Chart | Highlight key predictors of non-response |

## Model Performance 
| Metric | Value |
|--------|-------|
| ROC-AUC Score | 0.9966  |
| Accuracy | 94% |
